The following files are included in this repository: the workflow figure, Jupyter notebooks, and the CSV library template named “15kV_Stds_Lib.csv”, which must exist before the workflow can proceed. These files are the original work of Thomas Lam and are shared for use with the accompanying manuscript titled “Open-Source Workflow for NMF to Discretized Standards-Based SEM-EDS Quantification,” submitted to Microscopy and Microanalysis on July 12, 2026.

Thomas Lam is the author of this manuscript and can be contacted at Lamt@SI.edu.

This GitHub repository contains the following Jupyter notebooks: Albite.ipynb (EDS analysis of the standard for Na), Olivine.ipynb (EDS analysis of the standard for Mg), Orthoclase.ipynb (EDS analysis of the standard for K), Wollastonite.ipynb(EDS analysis of the standard for Ca), Rhodonite.ipynb (EDS analysis of the standard for Mn), Almandine.ipynb (EDS analysis of the standard for Fe), Jd_Only.ipynb (EDS quantification of a jadeite-only region), Omp_Only.ipynb (EDS quantification of an omphacite-only region), SRM621.ipynb (EDS quantification of a standard reference glass), and JS006_0p31.ipynb (EDS NMF analysis, component masks, and refinements for phase-specific quantification of a multiphase region in a jadeite sample). Due to the size of the raw .raw and .rpl files, the associated data are hosted in the Zenodo repository at: https://doi.org/10.5281/zenodo.21299375

The data are intended to be opened with open-source HyperSpy and Python software. Please cite the accompanying manuscript and GitHub repository when using these files.
