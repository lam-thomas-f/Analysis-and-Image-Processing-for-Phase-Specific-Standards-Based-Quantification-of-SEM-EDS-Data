# Open-Source-Workflow-for-NMF-to-Discretized-Standards-Based-SEM-EDS-Quantification
File repository for original work of Thomas Lam to shared and accompanying manuscript titled “Open-Source Workflow for NMF to Discretized Standards-Based SEM-EDS Quantification,” submitted to Microscopy and Microanalysis on July 9, 2026.
repository contatins the workflow figure, Jupyter notebooks, and the CSV library template named “15kV_Stds_Lib.csv”, which must exist before the workflow can proceed.
