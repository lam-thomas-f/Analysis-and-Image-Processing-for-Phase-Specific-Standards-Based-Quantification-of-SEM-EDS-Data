# Analysis-and-Image-Processing-for-Phase-Specific-Standards-Based-Quantification-of-EDS-data from SEM
File repository for original work of Thomas Lam to shared and accompanying manuscript titled "An Open-Source Workflow: Analysis and Image Processing, for Phase-Specific Standards-Based Quantification of EDS Hyperspectral Data from SEM" resubmitted to Microscopy and Microanalysis on November 18th, 2026. Repository contains 2 workflow figures, Jupyter notebooks (one to setup NeXL from Jupyter, 6 are standards specific, and 3 are quantification examples, one is the workflow from NMF with the image processing for masks and mask refinements for phase specific quantification), and the CSV file named "Standards_df" to be read into NeXL, CSV library template named “15kV_Stds_Lib.csv”, which must exist before the workflow can proceed.
