# Analysis-and-Image-Processing-for-Phase-Specific-Standards-Based-Quantification-of-EDS-data from SEM
File repository for original work of Thomas Lam to shared and accompanying manuscript titled "An Open-Source Workflow: Analysis and Image Processing, for Phase-Specific Standards-Based Quantification of EDS Hyperspectral Data from SEM" submitted to Microscopy and Microanalysis on July 12, 2026. Repository contains 2 workflow figures, Jupyter notebooks, and the CSV file named "Standards_df" to be read into NeXL, CSV library template named “15kV_Stds_Lib.csv”, which must exist before the workflow can proceed.
