# Analysis-and-Image-Processing-for-Phase-Specific-Standards-Based-Quantification-of-SEM-EDS-Data
File repository for original work of Thomas Lam to shared and accompanying manuscript titled “"Open-Source Workflow: Analysis and Image Processing, for Phase-Specific Standards-Based Quantification of SEM-EDS Hyperspectral Data” submitted to Microscopy and Microanalysis on July 12, 2026. Repository contains the workflow figure, Jupyter notebooks, and the CSV library template named “15kV_Stds_Lib.csv”, which must exist before the workflow can proceed.
